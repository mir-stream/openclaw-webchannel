## 확정된 제품 결정

- NATS relay는 자체 운영 또는 Synadia일 수 있는 **untrusted bus**다.
- `auto-admission`은 dev option으로도 남기지 않고 완전히 삭제한다.
- Gateway direct WebSocket과 legacy browser client를 완전히 삭제한다.
- Gateway는 browser를 위한 inbound endpoint를 절대 열지 않는다.
- BYO-NATS는 지원하되 authenticated NATS registration을 생략하지 않는다.
- 메시지 silent loss와 false-success는 허용하지 않는다.
- `(tenant, accountId)`는 하나의 logical agent identity를 나타낸다. 서로 다른 logical
  agent는 서로 다른 account를 사용한다.
- 같은 logical agent의 HA replica는 동일 identity key를 공유한다. 독립 key replica는
  미지원이며 명시적 교체 conflict로 표면화된다.
- Wire에는 별도 `agentId`가 없으며 account가 agent 격리·라우팅 축이다.
- SaaS library는 integrator가 multi-replica issuer용 safe enrollment store를 구현할 수
  있는 atomic contract를 제공한다.
- demo/reference/example은 production 구현에 참고할 수 있을 정도로 안전해야 한다.
- 한 설치 단위는 10,000 lifetime user 미만으로 보지만 cap 도달 시 기존 key 삭제는 금지한다.

## 공통 Definition of Done

- Repository와 publish artifact에 Gateway direct WebSocket transport가 없다.
- Auto-admission과 인증되지 않은 key exchange가 없다.
- 모든 supported NATS topology가 authenticated registration을 사용한다.
- Active relay의 key substitution이 browser→agent, agent→browser 양쪽에서 실패한다.
- 모든 사용자 메시지는 `accepted`, `completed`, `failed` 중 관찰 가능한 결과로 귀결된다.
- 서로 다른 logical agent는 account 경계로 격리된다.
- 같은 account의 HA replica는 동일 identity key를 공유하며, 독립 key replica는 조용히
  덮어쓰지 않고 교체 conflict가 된다.
- Subject/JWT/bootstrap wire에 별도 `agentId`가 없다.
- Public SPI만으로 multi-replica-safe enrollment store를 구현할 수 있다.
- Production reference가 insecure default로 부팅되지 않는다.
